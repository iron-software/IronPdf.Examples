# Utilizing Custom Logging in C&num;

> Full guide: [Utilizing Custom Logging in C&num;](https://ironpdf.com/how-to/custom-logging/)


Custom logging is a method to design a log system that caters to the specific needs of your application or system. It involves the creation of log files to capture various kinds of information, events, and messages that the software emits during its operation.

### Quickstart: Implement Custom Logging with IronPDF

Kickstart your C# project with custom logging via IronPDF. This tutorial assists you in setting `LoggingMode` to `Custom` and integrating it with a bespoke logger class. This allows effective monitoring and management of application logs, directing all IronPDF messages to your specialized logger, enhancing the logging functionalities tailored to your specific requirements.

```cs
// Set IronPDF to use a custom log handler
IronSoftware.Logger.LoggingMode = IronSoftware.Logger.LoggingModes.Custom;
// Link IronPDF's logging to a custom logger
IronSoftware.Logger.CustomLogger = new MyCustomLogger();
```

## Custom Logging Example

To activate the custom logging capabilities, switch the `LoggingMode` attribute to `LoggingModes.Custom`. Then, assign your custom logger to the `CustomLogger` attribute.

```csharp
// Configure IronPDF for Custom Logging
IronSoftware.Logger.LoggingMode = IronSoftware.Logger.LoggingModes.Custom;
IronSoftware.Logger.CustomLogger = new CustomLoggerClass("system-wide logging");
```

By redirecting IronPdf logs to this bespoke logger instance, the log messages remain the same as those generated by IronPdf but are simply passed on to your custom logger. It's up to the designer of the custom logger to decide how to process these messages. Consider the following custom logger class for illustration:

```csharp
public class CustomLoggerClass : ILogger
{
    private readonly string categoryName;

    public CustomLoggerClass(string categoryName)
    {
        this.categoryName = categoryName;
    }

    public IDisposable BeginScope<TState>(TState state)
    {
        return null; // No operation
    }

    public bool IsEnabled(LogLevel logLevel)
    {
        return true; // Always enable logging
    }

    public void Log<TState>(LogLevel logLevel, EventId eventId, TState state, Exception exception, Func<TState, Exception, string> formatter)
    {
        if (!IsEnabled(logLevel))
        {
            return; // Skip logging if not enabled
        }

        // Implementation of log handling
        string logMessage = formatter(state, exception);
        // Use various attributes such as 'logLevel', 'eventId', etc., for detailed logs
        Console.WriteLine($"[{logLevel}] [{categoryName}] - {logMessage}"); // Example log to console
    }
}
```
